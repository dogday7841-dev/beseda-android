# Беседка для Android: как получить APK бесплатно

Это проект приложения-оболочки. Оно открывает ваш мессенджер в окне приложения, у него свой значок, оно работает на весь экран.
APK собирает бесплатный облачный сервис GitHub, ничего устанавливать на компьютер не нужно.

## Что понадобится
- Бесплатный аккаунт на https://github.com (регистрация по почте, карта не нужна).
- Запущенный сервер мессенджера (папка `beseda-server`).

## Шаг 1. Создайте репозиторий
1. Войдите на github.com, нажмите **+** справа вверху → **New repository**.
2. Имя любое, например `beseda-android`. Выберите **Public**. Нажмите **Create repository**.

## Шаг 2. Загрузите файлы
1. Распакуйте архив `beseda-android.zip`.
2. На странице нового репозитория нажмите **uploading an existing file**.
3. Выделите **всё содержимое** распакованной папки (папки `.github`, `app` и файлы `build.gradle`, `settings.gradle`, `gradle.properties`) и перетащите в окно браузера.
   Важно: `.github` должна загрузиться вместе с вложенными папками. Если её не видно в Проводнике, включите «Показывать скрытые элементы» (вкладка «Вид»).
4. Внизу нажмите **Commit changes**.

Если `.github` не загрузилась: в репозитории нажмите **Add file → Create new file**, в поле имени введите `.github/workflows/build-apk.yml`, вставьте туда содержимое одноимённого файла из архива и нажмите **Commit changes**.

## Шаг 3. Соберите APK
1. Откройте вкладку **Actions**. Если появится кнопка включения, нажмите её.
2. Сборка запускается сама после загрузки файлов (зелёная галочка через 3–6 минут). Либо выберите слева **Сборка APK** → **Run workflow**.
3. Откройте завершённую сборку, внизу в разделе **Artifacts** скачайте **Beseda-APK**. Это архив, внутри него `app-debug.apk`.

Если сборка закончилась красным крестиком, откройте её, скопируйте текст ошибки и пришлите мне, я исправлю.

## Шаг 4. Установите на телефон
1. Скопируйте `app-debug.apk` на телефон (через кабель, Telegram себе или почту).
2. Откройте файл. Android попросит разрешить установку из этого источника: разрешите.
3. Запустите «Беседка». При первом запуске введите адрес сервера:
   - дома, в одной Wi-Fi сети: `192.168.0.11:3000` (адрес из окна сервера),
   - через туннель Cloudflare: `что-то.trycloudflare.com`.
4. Зарегистрируйтесь или войдите.

Сменить адрес сервера позже можно кнопкой **Сервер** в левой панели или на экране ошибки.

## Что важно знать
- Это отладочная сборка (debug), для личного использования. В Google Play её не загрузить.
- Приложение не работает без запущенного сервера на вашем компьютере.
- Уведомлений при закрытом приложении нет.
- Проект не проверен на реальной сборке. Если GitHub покажет ошибку, пришлите её текст.
